# Референси Claude Design

Сюди складаються макети з claude.ai/design, за якими переносяться
сторінки. Це вихідний матеріал, а не частина збірки — Vite їх не бачить,
бо тека поза `src/` і `public/`.

## features-page.claude-design.html

Проєкт: `9f36daee-8833-4ca7-801c-54fc4f2c05c6`
Файли в проєкті: `Features Page.dc.html`, `support.js`

Самодостатній HTML із кастомними елементами `<x-dc>` і повністю
інлайновими стилями. Побудований на нашій же мові: та сама змінна
`--accent-rgb`, JetBrains Mono, анімації названі як наші (`sweepDown`,
`scanSweep`, `ctaPulse`). Тобто це розвиток поточної сторінки, а не
заміна на щось стороннє.

`support.js` тут не збережений — це рантайм самого Claude Design, для
переносу в React він не потрібен. За потреби читається з проєкту.
